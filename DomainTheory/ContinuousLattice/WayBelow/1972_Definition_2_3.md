# Definition 2.3

The proofs of these statements can be safely left to the reader.

**2.3 Definition.** A *continuous lattice* is a complete lattice $D$ in which for every $y \in D$ we have:

$$
y = \bigsqcup x \in D : x \ll y.
$$
